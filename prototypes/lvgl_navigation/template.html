GTE Front Panel

Prototype, iteration 7: the page carousel with every Config Parameter editable on the device, using sw-001's colours and startup screen. Click the keys under the screen, or press 1–4; hold a key where its label shows a second, smaller action (2 s for editor shortcuts, 3 s for destructive confirmations).

How it behaves

  • Soft Key 1 = Next screen, wrapping: Home (the Application), each Service, Warnings, About (Core). On a page too long to fit, Soft Keys 2/3 scroll (▲ ▼) without editing. Soft Key 4 = Edit on every page.
  • Edit gives ▲ ▼ Edit Back: Edit (Soft Key 3) shows only on a Config Parameter; on a Status Value it is blank and does nothing. Colour does not distinguish them. Back is Soft Key 4.
  • Numbers: ▲ ▼ by the step, Save, Back. Booleans: ▲ ▼ toggle. Text: ▲ ▼ cycle the highlighted character through the editable character list (A–Z, a–z, 0–9, space, . and -); ▶ moves right and wraps, including one past the end; Del deletes and shifts left. Hold ▶ for 2 s to Save, hold Del for 2 s for Back.
  • Secrets (e.g. the Home Assistant password) show as •••• and the editor starts blank.
  • Warnings: Edit, then ▲ ▼, Clear, Clear all (hold for Back). Saving runs the same checks as the web page and SCPI; a refusal needs OK. Key labels hide after 5 s only on the Application's own screens.
